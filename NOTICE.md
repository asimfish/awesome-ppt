# Source and license notes

AwesomePPT's original skill code, documentation, layouts and synthetic archive-retrieval examples are offered under the GNU Affero General Public License, version 3. See [LICENSE](LICENSE).

**Public dataset.** The Iris input, its summary.csv derivative and the Iris measurements reproduced in our talk, PDF and README artwork are attributed to R. Fisher (1936), UCI Machine Learning Repository. The frozen file, DOI, CC BY 4.0 link and transformations are recorded in the [source note](examples/iris/SOURCE.md).

**Executable dependencies.** The distribution declares external Python packages in [requirements.txt](research-deck/requirements.txt). PyMuPDF is offered by its authors under AGPL and a separate commercial license. Pandoc and LibreOffice, when installed, run as separate local tools. Consult their upstream terms when packaging a runtime. [PyMuPDF licensing](https://pymupdf.readthedocs.io/en/latest/about.html) · [Pandoc](https://pandoc.org/) · [LibreOffice licenses](https://www.libreoffice.org/about-us/licenses/)

**Design references.** AwesomePPT uses original slide designs informed by academic presentations and publicly documented templates. The README links actual slides rendered by this project. The hero lettering is rasterized with DejaVu; the font files are external build inputs. [Design references](research-deck/UPSTREAM.md) · [DejaVu fonts](https://dejavu-fonts.github.io/License.html)

**University resources.** The campus showcase ships original, unbranded AwesomePPT examples. School marks, source decks, internal tool links and downloaded institutional templates stay in the user's local workspace. The catalog links to official institutional distribution pages. [Campus sources](research-deck/references/campuses.md)

**Botanical plate.** The Iris cover reproduces James Sowerby’s public-domain plate of *Iris versicolor* in Curtis’s *The Botanical Magazine*, vol. I, pl. 21. The scan comes from the Project Gutenberg edition. [Edition and credits](https://www.gutenberg.org/ebooks/17198) · [Source note](examples/iris/SOURCE.md)
