# 参考作者成稿重编

适用于用户明确把自己的会议报告、答辩或路演作为质量参照的场合。先看原稿放映画面和讲解顺序。记录最值得保留的几页，以及观众在每页能观察或判断的具体事情，例如找到两个策略的动作差别、顺着箭头读完模型、从一个界面字段追到实验记录。借用校方底图时，技术内容仍由项目原件提供。

如果用户尤其认可原稿的布局，直接在原生 PPTX 的副本上修订。保留封面上的署名与机构关系、正文母版、组合图形和交互标注。先确定页面的阅读顺序，再安排新版文字。三个实验条件需要同时对照时，保留三段视频或三组等比例画面；工作台有关键字段时，可从同一帧取局部放大图并框出出处。中文标题要核对渲染后的实际字体，回退字体的笔画粗细和字宽可能改变整页层级。

| 原稿中的证据 | 重编时的取舍 | 投影时检查 |
|---|---|---|
| 实验视频、动作对照 | 保留同一时间窗的两个执行过程。挑能说明差别的一帧做海报，注明左右分别是什么 | PPTX 内嵌视频能打开。仅看 PDF 时也能理解操作条件与指标 |
| 论文方法图、系统架构 | 从原始图件或论文 PDF 取图。在观众需要跟读的位置放大模块名、箭头或输入输出 | 关键路径在投影尺寸上可读，阶段之间的依赖关系能复述 |
| 工作台、设备、实验日志 | 跟随一次实际使用路径。从屏幕中选取能辨认的配方、状态或输出，用原生文字标出该看哪里 | 观众能说出刚才操作的是哪个案例、得到了什么记录 |
| 多条件实验与基准 | 主结果保留基线、单位、对照条件及比较对象。需要压缩时，把支持关键结论的分项留在附近 | 从图表可以重读标题中的数值，仿真、开环回放与闭环实测分别标明 |

在工作目录根据具体图件安排版面。并列实物、影片和原生图表可用 python-pptx 自编，然后用本 skill 的 `preview` 与 `check --pdf` 核对。使用 JSON 起稿时，`video` 页型可以直接嵌入 MP4 及其代表帧。保留图件页码、视频出处与原始时间区间，标注为展示而作的裁切或静音。

旧 PPTX 中的方法图有时在 PDF 预览里变成空白。对照对象关系和原稿检查该位置，再到原始论文、模型输出或图形资源中恢复。部分 macOS Office 生成的 EMF 在注释记录中包含 PDF 表示；确认能解码且内容与该原图一致后，可从中渲染图版。

最终将原稿与新版中承担同一讲解任务的页面并排。逐页检查删减后还能否读出原条件、关键过程和结果；视频页另查静态预览。根据这一轮对照调字体、裁切和叙事顺序。结构校验通过以后，仍需看实际放映画面。

用 `python3 scripts/deck.py compare 原稿.pdf 修订稿.pdf 对照.pdf --pairs 1:1 6:2 9:7` 对照封面、实验页和结果页。页码按两份 PDF 实际放映顺序计数。左右两页共享展示宽度，缩放保留各自的原始比例。

## 投影字号与图幅

在 13⅓ × 7½ 英寸的宽屏上，正文页标题可以从 32–40 pt 起排，解释句从 22–26 pt 起排，观众需要读出的轴标签和图例从 16–20 pt 起排。两张实验图必须在同一页比较时，给它们相同的有效显示尺度。校徽、作者署名、文献编号与答疑表格各按用途安排。

先保留支撑标题所需的图、条件与单位。方法图旁重复列出的模块名、图表旁重复抄录的整张表、截图外层的装饰框都可以让出空间。方法和效果需要分别讲解时拆成两页。横幅图配一句下方图注，纵向照片则可借用侧边留白。截取界面时，保留字段名、所选对象、数值和单位，在备注中写清截图出处。

把 PDF 切到单页适宽，按报告时的顺序指认操作、条件、坐标轴和结果。测的是图中有效内容的尺寸：图片框即使铺满整页，自带白边和图内小字仍会占掉读图空间。无法辨认的细节可从原件裁出一段放大；需保留的整体关系放在附页。检查长标题与校徽的间距，以及放大图例后是否遮挡横轴。
